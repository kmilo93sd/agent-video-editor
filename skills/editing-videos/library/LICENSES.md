## Generated here: 32 sounds, dedicated to CC0

No third-party recording is involved, except in the composites listed below, which only use CC0 material
from this file. All of them are dedicated to CC0.

**With ffmpeg (3):**

- `whoosh-soft`, `whoosh-short`: filtered pink noise with an envelope, generated with `ffmpeg` (`anoisesrc`,
  `bandpass`, `afade`).
- `typing-clicks-3s`: a sequence built from `click2`, `click4` and `click5` of Kenney UI Audio (CC0), with
  random timing and volume from a fixed seed. A derivative of CC0 material.

**With [`tools/synthesize.py`](tools/synthesize.py) (29):** numpy (filtered noise, sine and bell partials,
envelopes, synthetic reverb; fixed seeds), with `ffmpeg` only to decode the CC0 sources of the composites.

- Pure synthesis: `riser-short-2s`, `riser-medium-4s`, `riser-long-8s`, `swell-soft-3s`, `whoosh-medium-1s`,
  `whoosh-long-2s`, `whoosh-reverse-1s`, `reverse-cymbal-2s`, `downlifter-2s`, `send-whoosh-up`, `glitch-soft-1`,
  `glitch-soft-2`, `stinger-calm-pad`, `stinger-serious-low`, `stinger-energetic-hit`, `stinger-intro-bells`,
  `stinger-outro-soft`, `success-chime`, `check-mark`, `error-buzz-soft`, `alert-soft`, `countdown-beeps-3-2-1`,
  `beep-short`, `ambience-room-tone-30s`, `ambience-office-hvac-45s`.
- Composites of CC0 material: `cash-register-cha-ching` (Kenney rpg-audio handleCoins.ogg plus a synthesized
  register bell), `stamp-thud` (Kenney rpg-audio bookPlace1.ogg plus impact-sounds impactSoft_medium_000.ogg),
  `calculator-keys` (Kenney ui-audio click2.ogg and click3.ogg, pitched up and sequenced),
  `ambience-office-busy-45s` (synthesized room tone plus typing from the unicaegames keyboard pack, Kenney ui-audio
  mouseclick1.ogg and «Paper Sound - 3.wav» from Luckius).

To reproduce them (Python 3 with numpy, and `ffmpeg` on the PATH):

```bash
python tools/synthesize.py --out raw/                      # the 25 pure-synthesis sounds
python tools/synthesize.py --out raw/ --sources downloads/ # all 29
```

`downloads/` is a folder with the Kenney rpg-audio, ui-audio and impact-sounds zips, the unicaegames keyboard
soundpack and Luckius' paper sounds unzipped inside it (URLs above); files are found by name. The output is
raw: 16-bit WAV at 48 kHz, peak-normalized to -6 dBFS, the same bytes on every run. The library files are
those raw files after the processing below.

## Content ID risk

CC0 does not stop a third party from registering the same track in Content ID. Nobody checked whether any of
the music tracks is registered, and there is no way to guarantee it. If a claim arrives, dispute it in YouTube
Studio with the link to the OpenGameArt page above, which shows the CC0 license. See
[`../references/licenses.md`](../references/licenses.md).

## Processing

The files here are no longer byte for byte the originals. The full rule is in `catalog.json` → `criteria`:

- **Effects, stingers and ambience:** mono WAV, PCM 16 bit, 48 kHz, at -22 LUFS integrated with a -1 dBTP
  ceiling, with the limiter rule of `criteria.effects` (never on clicks and typing). In the 98 files added on
  4 October 2026, leading and trailing silence was trimmed and a fade-out was added where a file ended
  abruptly; loops were left untouched.
- **Music:** stereo MP3, 192 kbps, 48 kHz, at -16 LUFS with a -1.5 dBTP ceiling.
- The first 30 files (27 effects and the three music tracks listed first above) were first published at
  44.1 kHz, the music as 160 kbps MP3. On 4 October 2026 they were resampled to 48 kHz with ffmpeg
  (`aresample=48000:filter_size=64:phase_shift=12:cutoff=0.97`), the music re-encoded to 192 kbps, and every
  value in the catalog re-measured.

Measured values (duration, LUFS, true peak, gain applied) are in `catalog.json`; `node verify.mjs` checks
them against the files.
